# SeatShuffle

A premium table seating arranger application.

## Features
- **Smart Shuffle**: Randomly assigns seats with a smooth 5-second animation.
- **Flexible Layouts**: Choose from Round, Square, or Rectangular tables.
- **Premium UI**: Glassmorphism design with dark mode aesthetics.
- **Sound Effects**: Procedurally generated shuffle and completion sounds.

## Getting Started

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Start the development server:
    ```bash
    npm run dev
    ```

3.  Open the link provided (usually `http://localhost:5173`) in your browser.

## Usage
1.  Enter names in the text area (comma-separated).
2.  Select the table shape.
3.  Click **Shuffle Seats**.
4.  Watch the animation and see the final arrangement!
